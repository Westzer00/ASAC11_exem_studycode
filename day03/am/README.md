# 주문 관리 프로그램

주문번호를 입력하여 주문을 조회하거나 삭제하는 프로그램입니다.

## 기능

- 주문번호로 주문 조회
- 주문번호로 주문 삭제
- 주문이 없으면 안내 문구 출력

## 실행 방법

### 주문 조회

```bash
python order_search.py
```
### 주문삭제
```bash
python feature-delete_order/delete_order.py
```
### 실행예시

```bash
조회할 주문 번호를 입력하세요: 2

주문번호 : 2
고객명   : 김철수
메뉴     : 카페라떼
수량     : 1
가격     : 5000원
상태     : 주문 대기
```
