# 동일한 분류 문제에 프롬프트를 적용해보는 실습 진행
### 질문 종류
1. 단순 질문
2. 명확한 지시사항 포함
3. Few-shot 예시 포함
### 실험 설계

```bash
감정 분류 데이터 준비
        ↓
프롬프트 3종 작성
        ↓
Temperature 2종 적용
        ↓
각 조건을 동일한 문장으로 반복 실행
        ↓
원본 응답 CSV 저장
        ↓
정확도·형식 준수율·평균 길이 계산
        ↓
README에 결과표와 해석 작성
```
***
### 비교 항목
- [x] 정확도
- [x] 출력 형식 준수
- [x] 응답 길이
- [x] Temperature 변화
- [x] 잘못된 정보 생성 여부
***
### 코드 흐름
```bash
입력 문장
    ↓
make_prompt()로 프롬프트 생성
    ↓
Gemini API 호출
    ↓
원본 응답 output 저장
    ↓
extract_label()로 라벨 추출
    ↓
정답과 비교
    ↓
형식 준수 여부 확인
    ↓
응답 길이 계산
    ↓
results.csv 저장
```

| 조건          | 관찰 결과                                |
| ----------- | ------------------------------------ |
| 단순 질문       | 모델이 `만족`, `분노`, `불만`처럼 자유로운 감정 표현 사용 |
| 명확한 지시      | 모두 지정된 라벨 하나만 출력                     |
| Few-shot    | 예시 형식을 그대로 따라 라벨 하나만 출력              |
| Temperature | clear와 few-shot에서는 이번 실행에서 차이가 없었음   |

> simple → 사용할 라벨만 제시

> clear → 사용할 라벨 + 하나만 출력하라는 형식 지시

>few_shot → 사용할 라벨 + 형식 지시 + 예시 제공
