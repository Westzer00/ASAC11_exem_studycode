# 동일한 문서 집합에 다음 검색 방식을 적용 & 비교 

1. TF-IDF
2. BM25
3. Embedding 검색

### 테스트 질문
* 원문과 같은 단어를 사용하는 질문
* 의미는 같, 다른 단어를 사용 질문
* 오류 코드나 제품명이 포함된 질문
* 의미가 다른데 단어가 유사한 질문

## 코드 구현 흐름
```
documents.json에서 문서 불러오기 
→ TF-IDF, BM25, Embedding 검색 준비 
→ 테스트 질문을 각 검색 방식에 입력 
→ 검색 점수가 가장 높은 문서 Top-1 선택 
→ 검색 방식별 결과를 표로 비교 
→ 터미널 출력 및 results.csv 저장
```

### documents.json
> 검색에 사용할 문서 집합을 저장 
각 문서는 제목과 본문으로 구성되며, 세 가지 검색 방식 모두 동일한 문서 사용!
```
{
  "title": "문서 제목",
  "content": "문서 내용"
}
```

### retrieval.py
> 검색 실험을 실행하는 파일
주요기능
1. documents.json 문서 불러오기
2. 테스트 질문 정의
3. TF-IDF 검색 실행
4. BM25 검색 실행
5. Embedding 검색 실행
6. 각 검색 방식의 Top-1 문서 선택
7. 결과표 터미널 출력
8. 결과를 results.csv로 저장
### result.csv
> 각 질문에 대한 검색 방식별 Top-1 결과를 저장
결과표
* 질문 유형
* 질문 내용
* TF-IDF 검색 결과
* BM25 검색 결과
* Embedding 검색 결과

#### 실제 결과
| 질문 유형        | TF-IDF | BM25 | Embedding | 해석                                             |
| ------------ | ------ | ---- | --------- | ---------------------------------------------- |
| 같은 단어        | 정답     | 정답   | 정답        | 세 방식 모두 정확히 검색                                 |
| 같은 의미, 다른 단어 | 오답     | 오답   | 정답        | Embedding만 의미를 이해해 검색                          |
| 오류 코드        | 정답     | 정답   | 정답        | `E101`이라는 정확한 문자열 덕분에 모두 성공                    |
| 유사 단어, 다른 의미 | 오답     | 오답   | 정답        | Sparse 방식은 `자바` 단어에 집중하고, Embedding은 여행 의미를 구분 |
=> TF-IDF와 BM25는 로그인이라는 동일 단어 때문에 잘못 찾았지만, Embedding은 [암호를 새로 바꾸다] = [비밀번호 재설정]이라는 의미를 찾음
=> TF-IDF와 BM25는 자바라는 단어에 영향을 받았고, Embedding은 여행하기 좋은 시기라는 문장 의미를 반영
