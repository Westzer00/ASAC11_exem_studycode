# 1. 목적

본 문서는 ABC Tech에서 사용하는 주요 IT 시스템의 사용 방법과 접근 권한 관리 기준을 정의한다.

모든 임직원은 회사 정책과 보안 정책을 준수하여 시스템을 이용해야 한다.

--------------------------------------------------

## 2. 주요 시스템

ABC Tech는 다음 시스템을 사용한다.

- Jira : 프로젝트 관리
- GitLab : 소스코드 저장소
- Confluence : 문서 관리
- VPN : 외부 네트워크에서 회사 시스템 접속

--------------------------------------------------

## 3. VPN

VPN(Virtual Private Network)은 회사 외부에서 내부 시스템에 접속하기 위한 서비스이다.

재택근무나 출장 중에는 반드시 VPN을 이용해야 한다.

VPN 계정은 인프라팀에서 생성한다.

VPN 계정은 보안교육을 이수한 직원만 활성화된다.

VPN 사용이 제한된 직원은 GitLab과 Confluence에 접속할 수 없다.

--------------------------------------------------

## 4. Jira

모든 프로젝트는 Jira에서 생성하고 관리한다.

프로젝트 생성 권한은 프로젝트 관리자(PM)에게 있다.

일반 개발자는 자신에게 할당된 작업만 수정할 수 있다.

--------------------------------------------------

## 5. GitLab

GitLab은 회사의 공식 소스코드 저장소이다.

모든 개발은 Git 브랜치 전략을 따라야 한다.

코드는 Merge Request를 통해 리뷰를 받은 후 병합한다.

GitLab 접근 권한은 개발팀 소속 직원에게 부여된다.

--------------------------------------------------

## 6. Confluence

Confluence는 회사의 공식 문서 관리 시스템이다.

회사 규정, 프로젝트 문서, 회의록은 모두 Confluence에 저장한다.

중요 문서는 문서 소유자의 승인 없이 삭제할 수 없다.

--------------------------------------------------

## 7. 계정 발급

신입사원 계정은 입사 첫날 생성된다.

계정 생성 요청은 인사팀에서 진행한다.

인프라팀은 계정을 생성하고 초기 비밀번호를 발급한다.

보안교육을 완료하면 VPN 계정이 자동으로 활성화된다.

--------------------------------------------------

## 8. 접근 권한

직원의 시스템 접근 권한은 소속 부서와 담당 업무에 따라 다르다.

퇴사하거나 부서를 이동하면 기존 권한은 즉시 회수된다.

권한 변경은 인사팀 요청 후 인프라팀이 처리한다.

--------------------------------------------------

## 9. 장애 대응

시스템 장애가 발생하면 Service Desk에 먼저 문의한다.

VPN 장애는 인프라팀에서 처리한다.

GitLab 장애는 개발 플랫폼 담당자가 대응한다.

Confluence 장애는 IT 운영 담당자가 관리한다.
