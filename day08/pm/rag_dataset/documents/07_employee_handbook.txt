# 1. 목적

본 안내서는 신입사원이 입사 후 첫 주 동안 수행해야 하는 교육과 업무 절차를 안내한다.

모든 신입사원은 본 안내서의 일정에 따라 교육을 이수해야 한다.

--------------------------------------------------

## 2. 입사 첫날

인사팀에서 입사 등록을 완료한다.

사원증을 발급받는다.

회사 이메일 계정을 생성한다.

노트북과 기본 장비를 지급받는다.

회사 계정 생성은 인프라팀에서 수행한다.

--------------------------------------------------

## 3. 둘째 날

정보보안 교육을 수강한다.

개인정보 보호 교육을 수강한다.

회사 보안 정책을 확인한다.

보안교육을 완료해야 VPN 계정을 활성화할 수 있다.

--------------------------------------------------

## 4. 셋째 날

VPN 계정을 활성화한다.

GitLab 계정을 확인한다.

Confluence 계정을 확인한다.

Jira 계정을 확인한다.

계정이 정상적으로 생성되지 않은 경우 Service Desk에 문의한다.

--------------------------------------------------

## 5. 넷째 날

소속 프로젝트에 배정된다.

프로젝트 관리자는 Jira에서 프로젝트에 참여자를 등록한다.

프로젝트 문서는 Confluence에서 확인한다.

소스코드는 GitLab에서 관리한다.

--------------------------------------------------

## 6. 다섯째 날

개발 환경을 구축한다.

Git 저장소를 Clone한다.

샘플 프로젝트를 실행한다.

개발팀 멘토와 코드 리뷰 절차를 실습한다.

--------------------------------------------------

## 7. 필수 확인 사항

보안교육을 완료하지 않으면 VPN을 사용할 수 없다.

VPN을 사용할 수 없으면 GitLab과 Confluence에 접속할 수 없다.

사내 시스템 이용 정책은 IT System Guide를 따른다.

보안 정책은 Security Policy를 따른다.

--------------------------------------------------

## 8. 자주 발생하는 문제

계정이 생성되지 않은 경우

→ 인사팀 또는 Service Desk 문의

VPN 접속이 되지 않는 경우

→ 보안교육 이수 여부 확인

GitLab 접속이 되지 않는 경우

→ VPN 연결 여부 확인

Jira 프로젝트가 보이지 않는 경우

→ 프로젝트 관리자(PM)에게 권한 요청
