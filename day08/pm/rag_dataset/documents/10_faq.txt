# 1. 휴가는 언제까지 신청해야 하나요?

일반적인 연차는 최소 3일 전에 그룹웨어를 통해 신청해야 합니다.

긴급한 상황이라면 사후 신청도 가능하지만 팀장에게 사유를 제출해야 합니다.

자세한 내용은 HR Policy를 참고하세요.

--------------------------------------------------

# 2. 집에서 회사 시스템에 접속하려면 어떻게 하나요?

재택근무나 외부 근무 시에는 VPN을 이용해야 합니다.

VPN은 보안교육을 완료한 직원만 사용할 수 있습니다.

VPN 설정 방법은 IT System Guide를 참고하세요.

--------------------------------------------------

# 3. VPN 연결이 되지 않습니다.

다음 사항을 확인하세요.

- 보안교육을 완료했는지 확인합니다.
- VPN 계정이 활성화되어 있는지 확인합니다.
- 문제가 계속되면 Service Desk에 문의합니다.

--------------------------------------------------

# 4. 프로젝트는 어디에서 생성하나요?

모든 프로젝트는 Jira에서 생성합니다.

프로젝트 생성 권한은 프로젝트 관리자(PM)에게 있습니다.

--------------------------------------------------

# 5. 코드는 어디에 저장하나요?

모든 소스코드는 GitLab에서 관리합니다.

개인 PC나 외부 저장소에 보관해서는 안 됩니다.

--------------------------------------------------

# 6. 프로젝트 문서는 어디에서 관리하나요?

프로젝트 설계 문서, API 문서, 회의록은 모두 Confluence에서 관리합니다.

--------------------------------------------------

# 7. 코드를 바로 Main 브랜치에 올릴 수 있나요?

아니요.

개인 브랜치에서 작업한 후 Merge Request를 생성하고 코드 리뷰를 받아야 합니다.

--------------------------------------------------

# 8. 출장 후 무엇을 해야 하나요?

출장 종료 후 7일 이내 출장 결과 보고서를 작성해야 합니다.

출장비는 14일 이내 정산해야 합니다.

--------------------------------------------------

# 9. 해외 출장은 누가 승인하나요?

해외 출장은 본부장의 승인을 받아야 합니다.

14일을 초과하는 장기 출장은 대표이사의 추가 승인이 필요합니다.

--------------------------------------------------

# 10. 신입사원은 첫 주에 무엇을 하나요?

입사 등록

↓

보안교육

↓

VPN 활성화

↓

프로젝트 배정

↓

개발 환경 구축

순서로 진행됩니다.

--------------------------------------------------

# 11. GitLab에 접속되지 않습니다.

먼저 VPN 연결 여부를 확인하세요.

VPN이 정상인데도 접속되지 않으면 Service Desk에 문의하세요.

--------------------------------------------------

# 12. 회의록은 어디에 저장하나요?

회의록은 Confluence에서 관리합니다.

회의 후 가능한 빠르게 등록하는 것을 권장합니다.

--------------------------------------------------

# 13. 비용 정산은 어떻게 하나요?

출장 종료 후 그룹웨어에서 비용을 정산합니다.

모든 영수증은 전자 파일 형태로 제출해야 합니다.

--------------------------------------------------

# 14. 계정은 누가 만들어 주나요?

인사팀의 요청을 받은 후 인프라팀이 계정을 생성합니다.

--------------------------------------------------

# 15. 비밀번호는 얼마나 자주 변경해야 하나요?

비밀번호는 90일마다 변경해야 합니다.

영문, 숫자, 특수문자를 포함하여 최소 12자 이상으로 설정해야 합니다.
