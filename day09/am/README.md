# Adaptive_Iterative_Retrieval 실습

```diff
+ Baseline

질문 → Dense Retrieval 1회 → Top-3 반환
```
```diff
+ Improved

질문
→ 검색 필요 여부 판단
→ 1차 검색
→ 검색 품질 평가
→ 필요하면 Query 변경 후 2차 검색
→ 근거 충분: 결과 반환
→ 근거 부족: 답변 거부
```

## 검색 정책

```erlang
질문 입력
↓
검색이 필요한가?
├─ 아니오 → 검색하지 않음
└─ 예
   ↓
   1차 Dense Retrieval
   ↓
   결과 평가
   ├─ 유효 결과 0개
   │  → Query Rewrite 후 2차 검색
   │
   ├─ 문서 내용 충돌
   │  → 최신·신뢰도 높은 문서로 2차 검색
   │
   ├─ 최고 점수가 기준 이하
   │  → Multi-query로 2차 검색
   │
   └─ 충분함
      → 검색 종료
↓
2차 검색도 근거 부족
→ 답변하지 않음
```
구현 사항
```
1차 검색
├─ 0개 취급 → Query Rewrite
├─ 충돌 → 최신 공식 규정 재검색
├─ 낮은 점수 → Multi-query
└─ 정상 → 종료

2차 검색도 낮은 점수
→ 답변하지 않음
```

### 조건이 동시에 발생했을 때는 다음 순서로 판단

```markdown
1. 결과 0개 <- 점수가 너무 낮은 문서는 검색 결과로 인정하지 않는 규칙이 필요
2. 문서 충돌 => Metadata를 이용해서 충돌을 표시하는 방식으로 진행하기
3. 최고 점수 낮음 => 하나의 질문을 서로 다른 표현 두 개로 만들어 각각 검색
4. 정상 종료
```

### 반복 횟수 제한
`MAX_ROUNDS = 2`  
_1차 검색 → 필요할 경우 2차 검색 ==> 무조건 종료_

```diff
- 주의점

+1차 검색:
   1회

+ 2차 Multi-query: 
   Query 1 검색
   Query 1 검색


최대 검색 호출 수: 총 3회
최대 검색 라운드: 총 2회
```

\=> 검색 라운드와 검색 호출 횟수는 다름!

### 중단 조건
1. 최고 점수 0.60 이상  
2. 충분한 근거 문서 확보  
3. 최대 2라운드 도달  
4. 동일 Query가 다시 생성됨  
5. 2차 검색 후에도 유효 문서가 없음

### 실패시 사용자 응답도 구성
```
관련 문서에서 질문에 답할 충분한 근거를 찾지 못했습니다.  
질문을 더 구체적으로 작성하거나 최신 담당 부서 자료를 확인해 주세요.
```
## 핵심 함수
```
search()
= 질문·문서를 벡터로 비교하여 Top-3 검색

rewrite_query()
= 사용자 표현을 문서 검색용 표현으로 변경

has_conflict()
= 문서에서 서로 다른 숫자가 나오는지 확인

adaptive_search()
= 1차 검색 후 필요하면 2차 검색

main()
= 모든 질문을 실행하고 results.csv 저장
```
