# Pointwise / Pairwise Judge

## 실습 목적
20개의 RAG 답변을 Pointwise와 Pairwise 방식으로 평가하는 실습
API는 사용하지 않고, 미리 작성한 사람 평가와 LLM Judge 평가 결과를 사용!!

## 파일 구성

```text
day10/pm/
├── README.md
├── main.py
└── questions.py
```

## 데이터 구성

- 질문
- 검색 Context
- RAG 답변
- 참고 정답
- 사람 평가
- LLM Judge 평가
- Judge 평가 근거

## 실행

```bash
python main.py
```

=> 결과는 `results.csv`에 저장

## 실험 내용

### 1. 점수만 출력

RAG 답변을 1~5점으로 평가한 결과

### 2. 근거와 점수 출력

점수와 함께 평가 근거를 확인하는 실험

### 3. Pairwise 비교

RAG 답변과 비교 답변 중 더 좋은 답변을 선택하는 실험

### 4. 답변 순서 변경

답변 A와 B의 순서를 변경하여 순서 편향이 있는지 확인

### 5. 긴 답변과 짧은 답변 비교

답변 길이가 Judge 평가에 영향을 주는지 확인

### 6. 사람 평가와 일치율 계산

사람 평가와 LLM Judge 평가가 얼마나 일치하는지 계산

## 결과

- 사람 평가와 정확히 일치율을 계산
- ±1점 이내 일치율을 계산
- Pairwise 답변 순서 일관성을 계산
- 긴 답변과 짧은 답변의 평가 차이를 확인

## 결론
LLM Judge는 사람 평가와 대체로 비슷한 결과를 보임!! 
But, 출력 형식, 답변 순서, 답변 길이에 따라 평가가 달라질 수 있음을 확인
